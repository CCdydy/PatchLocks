# Data and weights

[`data/manifest.txt`](../data/manifest.txt) is the authoritative list: every checkpoint and
dataset the code reads, its path relative to the repository root, its size, and what uses it.
None of it is tracked by git. Arrange the files under a data root with the same relative layout
and run `bash pipeline/00_link_data.sh /path/to/DATA_ROOT`.

| Category | Contents | Size |
|---|---|---|
| `weights` | paper diffusion model (`v16/e2a_cw15/v14_best.pt`) + multi-view fuser, strand codec, single-view baseline (Table 1), E1 recipe ablation, Table 2 baselines (deterministic latent, scalar regression) | ~0.6 GB |
| `ours` | synthetic corpus `renders_mv` (1,600 patches × 4 views), frozen test sets (n=160 in-distribution, n=80 extrapolation), archived grooms and renders used by the figures | ~28 GB |
| `derived` | per-animal inputs preprocessed from the NeuralFur / ARTEMIS captures: surface patch packs, geodesic patch covers, cameras, masks, orientation maps | ~15 GB |
| `thirdparty` | NeuralFur released furless meshes and grooms, the ARTEMIS panda capture, Blender 4.5.10 LTS | ~10 GB |

## Regenerating our data

**Synthetic training corpus** — `bash pipeline/01_synthetic_data.sh` (see the script header).
Coat counts: ultra_short 80, short_dense 112, short_double_standoff 96, wiry 96, wavy 208,
curly 256, long_golden 272, long_silky 208, fluffy_double 272; colour schemes rotate through
solid / two_tone / bicolor / tabby / tipped. The train/validation split is not stored: it is the
patch-level 1,360/240 split drawn with seed 0 by `patchlocks/v14/v14_common.py`.

**Frozen test sets** — released and frozen; the paper numbers must be computed on the released
files. They were generated by:

* in-distribution, n=160: `patchlocks/experiments/rebuttal_2027/gen_testset_B.sh` (seeds 610000+,
  one tenth of the training coat counts), Blender renders with
  `patchlocks/data_gen/photoreal_render_loop_v8.py --views 4 --res 256 --samples 56 --seed0 710000`,
  then `testB_postrender.sh`;
* extrapolation, n=80: `gen_ood_patches.py --n_per 20` (seeds 810000+, four beyond-range coats),
  renders with `--seed0 910000`, then `ood_postrender.sh`.

`*_FROZEN_manifest.txt` lists the frozen directories. The generators now default to writing under
`outputs/testsets/` so the frozen sets cannot be overwritten by accident.

**Strand codec** (`fur_strand_codec_v6upright.pt`) — fine-tuned from the DiffLocks strand VAE
(`checkpoints/strand_vae/strand_codec.pt`) with `patchlocks/models/fine_tune_codec.py`
(4,000 iterations, batch 8192, lr 3e-4) on a pool of 500k strands built by
`patchlocks/data_gen/build_pool_v6.py` from 5,000 patches generated by `gen_v5_batch.py`
(`render_loop.py` / `v6_overnight.sh` render them; the pool uses only the strands). The
fine-tuning is not seeded, so a retrained codec differs from the released one.
